# Incremental Dwarf

Command dwarf to mine in a deadly mine to gather gems.

## About
**Incremental Dwarf** was created for the [**Godot Wild Jam #97**](https://itch.io/jam/godot-wild-jam-97) in 9 days by a team of 3.
